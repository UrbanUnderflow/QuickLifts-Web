# CAU web questionnaire: local implementation

Route: `/PulseCheck/questionnaire/cau`. Uses the native source fixture, replacing onboarding ID with name and email. Identity is self-reported, not verified. Responses remain in component memory until explicit Submit; reload loses unsent work. No automated email is sent. No respondent read endpoint is exposed.

Submission API: `/api/pulsecheck/questionnaire/cau`. Saves all supplied values in `pulsecheck-restricted-questionnaire-submissions`, with a random submission ID, source version, identity, individual field states, revision, and timestamp. Empty optional answers are marked skipped. Name and email are not document IDs. Retries with the same ID and payload are idempotent. The intake route bypasses global tracking and persisted app state. A shared invitation is a capability to submit, not proof of identity; per-person verified invites and rate limiting remain launch hardening work.

Deployment is disabled by default. Configure `CAU_QUESTIONNAIRE_COLLECTION_ENABLED=true` and a strong `CAU_QUESTIONNAIRE_INVITE_KEY` only after deployment review. Invite link format: `/PulseCheck/questionnaire/cau#invite=<key>`. The page reads the fragment into memory and removes it from the address bar. Do not place identifying information in URLs. Refresh requires the original invite link.

Deploy the Firestore rules before enabling writes. They deny all client reads and writes, including the compatibility fallback. Server SDK access bypasses these rules: verify service-account IAM, restrict human console access and downstream admin endpoints, and test deployed rules. No rules or production configuration were deployed by this change. No real submissions were created.

Future migration helper `redactMigratedFields` requires a verified receipt matching the source revision, replaces selected local fields with auntEDNA references, removes the original payload digest, and preserves other fields. It is a pure transformation only: the auntEDNA integration, receipt authentication, transactional write, retry orchestration and retention cleanup remain unimplemented. Never expose it to clients. Question definitions remain in the versioned fixture. Record identity and external references remain sensitive. Configure backup/PITR/export retention before claiming complete removal of original values.

Readiness: four focused model/rule-structure tests pass. Rule tests are static, not emulator or deployed authorization tests. Full collection is not legally certified by the collection name or these tests. Verify the applicable Google Cloud BAA, covered services and API hosting path, notice/agreements, and access controls before real sensitive submissions. Google guidance: https://cloud.google.com/security/compliance/hipaa/

## Browser-test deployment, September 8

An isolated static React build and Netlify function are deployed at https://cau-questionnaire-test--quickliftsapp.netlify.app. The invite capability is delivered separately. The test page requests fictional data only. Production homepage was not replaced. Deployed Firestore rules were patched from the current remote ruleset to exclude the new collection from signed-in fallback and deny all client access. Firebase Admin readback verified a synthetic complete answer value after HTTP 200 submission. Unauthenticated read and missing-invite submission returned 403; idempotent retry returned 200. Signed-in client verification could not run because local credentials and anonymous sign-in were unavailable; do not claim that check passed. No actual athlete data was entered by the agent. The browser welcome and auto-advance were checked.

Use scripts/build-cau-phone-preview.cjs for isolated rebuilds. CAU_PREVIEW_INVITE_KEY may inject the test capability into the private function artifact when Netlify draft runtime environment does not receive the variable. Never put that value in the public JS bundle or commit generated function artifacts. Netlify configuration keys were added; the draft required a private function-level override. The live test supports touch/text entry; native Nora narration and voice controls have not been ported to this web page. Real athlete collection still requires hosting/BAA, notice, account-access review and abuse-control work.
